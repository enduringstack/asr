# ADR-0002：分离本次会议标签与长期人物身份

## 状态

Accepted

## 背景

用户可能只想把当前会议的“说话人 A”改成一个易读名称，也可能希望以后继续识别此人。若姓名同时充当声纹主键，改名、同名人物和撤销误认都会破坏历史关联。

## 决策

使用稳定 `personId` 表示长期人物；每次会议另存 `clusterId → personId/displayNameOverride` 映射。UI 明确提供“仅本次改名”和“记住此人”两个操作。长期改名只修改 Profile 的 `displayName`，不改变 `personId`。

## 后果

### 正面

- 用户可以自由改名而不重建声纹。
- 同名人物、历史会议和本次临时标签可以正确表达。
- 错误绑定可在单次会议范围内撤销。

### 负面

- 需要结构化 SpeakerTurn 和额外映射存储。
- 现有纯文本说话人输出需要迁移。

### 中性

- 导出时可生成姓名快照，但内部仍以 id 关联。

## 备选方案

- 继续以姓名为声纹键：实现简单，但无法满足可靠编辑和跨会议身份。
