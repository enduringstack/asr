# ADR-0001：使用预训练多原型声纹，不做每人模型训练

## 状态

Accepted

## 背景

应用运行在 HarmonyOS 手机端，目标是识别固定 2–10 人并允许未知人员。工程已集成 sherpa-onnx 3D-Speaker 中文 embedding 模型。用户希望本人可主动注册，其他人可通过会议片段标记后被长期识别。

## 决策

本人主动注册保存 3 个经质量门禁的 embedding，并计算 L2 归一化中心向量；会议确认样本可受控加入并重新计算中心。注册只执行前向推理、聚合和保存，不进行反向传播或每人分类器训练。自动识别结果不能直接更新模板。

## 后果

### 正面

- 注册快、离线、可删除，适合端侧。
- 多原型比单次平均更能覆盖不同会议和录音距离。
- 不需要为每人收集正负训练样本。

### 负面

- 需要模型专属的阈值校准。
- 用户误标仍可能污染模板，因此必须提供候选状态和撤销。

### 中性

- 底层预训练模型仍可能在开发机上做统一域适配，但不属于第一版。

## 备选方案

- 单 embedding：改动少，但对误标和环境变化过于敏感。
- 每人训练分类器：数据、计算和维护成本不适合手机端小团队。
