# 声学场景双 95% 提升方案

## 成功口径

目标不是把当前 18 条固定音频调到全对，而是在来源隔离的六分类任务上同时达到准确率和宏召回率 95%。六类仍为地铁、高铁 / 城际列车、商场、咖啡厅 / 餐厅、音乐现场和其他；“其他”参与整体准确率，也参与宏平均。数据按录音地点、原始长录音、Freesound 上传者和近重复组隔离，拆成训练、校准和盲测三份。训练期间只看校准集；模型、温度和拒识阈值冻结后才运行盲测。固定 18 条只用于 App 可播放证据，不作为选模依据。

95% 是当前产品的发布门禁，不是可提前保证的自然界能力。作为外部难度参照，DCASE 2025 低复杂度十场景挑战的最佳系统准确率为 61.47%，未知设备更低；音频单模态对安静高铁、地铁和大型室内空间存在不可辨识样本。因此报告必须保留失败案例和置信区间，不能删难样本、使用文件名/标签推理或把已看过的测试集改称盲测。

## 数据改造

当前 508 条样本过少，尤其“其他”只覆盖有限机场和公交片段，高铁明确标签只有少量 FSD50K 音频。新语料先加入 TUT Acoustic Scenes 2017 development 的 4,680 条官方十秒场景音频，用其咖啡厅、列车以及十三类难负样本补足目标域；再从 TAU Urban Acoustic Scenes 2022 Mobile 按地点抽取地铁、商场和八类难负样本，覆盖不同城市与设备；FSD50K 继续只使用许可证和元数据可追溯的高铁、真实音乐现场、纯音乐和纯观众片段。

训练/校准/盲测的来源组比例固定为 70/15/15。每个集合至少 100 条/类；“其他”内部按机场、公交、地铁站、公园、广场、步行街、道路交通、电车、办公室、图书馆、家庭、普通音乐和普通人群分层采样，避免总体数字很高但单一负类失效。高铁类别的 UI 名称维持“高铁 / 城际列车”，普通列车数据只能作为弱标签，报告单独给出明确高速元数据子集的结果。

## 模型与端侧架构

比较三条路线：较大的 EfficientAT DyMN10 直接六分类；DyMN10 教师向 DyMN04 蒸馏；DyMN04/DyMN10 的分层双头模型。推荐第三条：主头判断五个目标场景，拒识头独立判断“目标场景还是其他”，最终再做温度标定。它直接针对当前“机场被商场吸收”的主要错误，又不需要在手机上部署两个完整模型。

Mac 训练阶段可使用 BEATs 或 DyMN10 作为离线教师，但手机只部署一个学生 ONNX。候选模型必须满足 ONNX Runtime 1.16.3 可执行、单窗静态输入、内存可控和真机 RTF 小于 0.25。若 DyMN10 达标而 DyMN04 蒸馏版未达标，允许采用约 40–45 MB 的 DyMN10；若两者都达标，优先更小的学生。INT8 只有在精度下降不超过 0.5 个百分点时才采用。

## 验收与 UI

训练报告同时输出总体准确率、宏召回率、逐类召回率、混淆矩阵、95% bootstrap 置信区间、明确高速子集和难负样本结果。盲测任一核心指标低于 95%，模型不得标记为达标，也不得覆盖 App 当前基线；继续补充错误类别数据并重新建立新的盲测集。

达标后更新 App 模型卡和门限，保留真实标签、模型输出、六类分数、耗时和可播放音频。覆盖安装只用 `hdc install -r`，不卸载、不清数据。真机验收包括 18 条固定集批测、至少一条错误样本播放、实时录音、页面滚动和截图；UI 不显示内部“演示/临时”措辞。
