# 固定测试音频播放设计

## 目标

固定测试页中的每条 AISHELL-4 和 AliMeeting 音频都可以直接试听，用户能够把说话人分段结果与原始内容对应起来。

## 交互

- 每条测试卡片显示“播放”按钮。
- 同一时间只允许播放一条音频；点击另一条时先停止上一条。
- 正在播放的卡片显示“停止”和当前进度/总时长。
- 固定性能测试运行时禁用播放；音频播放期间禁用“运行全部固定音频”，避免媒体解码抢占资源并污染 RTF。
- 离开页面时停止播放并释放播放器和 rawfile 文件描述符。

## 实现

新增单实例 `RawResourcePlayer`，通过 `ResourceManager.getRawFd()` 把 HAP 内 rawfile 的 fd、offset 和 length 交给 `AVPlayer`，不复制大音频到内存或应用目录。播放器通过回调把当前音频、播放位置、总时长和错误传回页面。页面只保存 UI 状态，测试 worker 与播放器相互独立。

## 异常处理与验证

资源打开、播放器创建、prepare/play、release 和 closeRawFd 的失败均记录日志并恢复为未播放状态。代码需要通过 ArkTS 单元测试编译、完整 HAP 构建和 `git diff --check`。真机安装遵循设备安全规则，只有用户在当前任务明确要求安装时执行。
