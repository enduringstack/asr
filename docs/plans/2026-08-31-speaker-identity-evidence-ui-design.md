# 声纹身份评测证据界面设计

## 问题

当前页面拥有 AISHELL-3 真值、CAM++ 预测、相似度和是否正确等真实字段，但信息被压缩成列表中的两行小字。运行前只能看到笼统的“真值”，运行后也无法快速建立“数据集是谁、模型认成谁、为什么接纳或拒绝、最终是否正确”的视觉对应关系。

## 设计结论

采用手机端逐条证据卡，而不是横向表格或二级详情页。页面由三层组成：顶部显示数据集协议和整体指标；中部提供全部、已知、未知、错误四种结果筛选；每条测试使用一张真值—预测对比卡。

每张卡固定展示：

1. 数据集标签：AISHELL-3 原始说话人 ID、测试组编号、已知或未知类型。
2. 实际标签：产品身份真值，例如“AISHELL 已知 01”或“未知说话人”。
3. 模型输出：CAM++ 最终预测身份；尚未运行时明确显示“等待模型输出”。
4. 决策证据：最高余弦相似度、接纳阈值 0.60、处理耗时，以及“高于阈值接纳/低于阈值拒绝”的说明。
5. 对比结论：正确、误识别、错误拒识、未知误接纳或处理失败，不只使用红绿颜色表达。
6. 原始音频：播放参与本次聚合评分的三段测试语音；注册样本与查询样本分离的说明保留在顶部。

## 状态

- 等待：真值始终可见，预测区域显示空状态。
- 建档：顶部显示正在建立的已知人物与注册样本进度。
- 识别：当前卡高亮并显示正在聚合三段查询语音。
- 完成：指标和筛选数量更新，卡片显示真实预测与判定证据。
- 错误：卡片保留真值并显示具体处理错误。

## 视觉

延续语音智能实验台的浅色背景、蓝色主操作和紫色声纹语义色。真值区域使用中性蓝灰，模型输出区域使用浅紫；正确结果使用绿色，错误使用红色，等待使用灰色。卡片保持 16 像素级内边距和清晰分区，避免一行塞入所有字段。

## 验收标准

- 不运行模型也能看清每条 AISHELL-3 的原始说话人 ID 和实际产品标签。
- 运行任一测试后，真值、预测、相似度、阈值和结论在同一卡内可见。
- 已知与未知结果的接纳逻辑文案准确，未知拒识不会被误写成“没有预测”。
- 原始测试音频仍可播放，播放和模型运行互斥。
- 测试继续使用隔离内存声纹库，不读取或写入个人声纹资料。
