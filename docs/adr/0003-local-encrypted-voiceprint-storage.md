# ADR-0003：声纹只在本机加密保存

## 状态

Accepted

## 背景

声纹是敏感生物特征数据。当前实现将旧模型的 512 维 embedding 作为普通 JSON 写入 Preferences，且模块允许备份恢复，不符合本功能的隐私目标。新 CAM++ 模型为 192 维，升级时还需要明确处理维度不兼容。

## 决策

使用 HUKS 管理设备绑定密钥，以 AES-GCM 加密版本化声纹档案。声纹不上传、不进入普通录音导出、不写日志，并排除系统备份。若无法细粒度排除声纹容器，则禁用其备份能力。

## 后果

### 正面

- 设备丢失或沙箱文件被复制时，明文 embedding 不直接暴露。
- 删除、重建和模型迁移有明确边界。
- 不引入服务端和账号系统。

### 负面

- 卸载、换机或密钥丢失后需要重新建档。
- 需要实现加密存储、损坏恢复和旧 Preferences 迁移。

### 中性

- 未来若需要跨设备同步，必须另行设计端到端加密和用户授权。

## 备选方案

- 普通 Preferences：实现最简单，但为明文持久化。
- 云端声纹库：支持同步，但扩大安全、合规和运维范围，第一版拒绝。
