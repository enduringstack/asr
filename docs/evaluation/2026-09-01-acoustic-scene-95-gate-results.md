# 声音场景 95% 发布门禁结果

## 结论

本轮没有达到发布门禁，不能替换手机中的现有模型。来源隔离校准集上的最佳结果为准确率 **73.87%**、宏召回率 **70.01%**，均低于 95%。盲测集仍保持封存，没有运行预测；App、手机模型和用户数据均未修改。

95% 是准确率和宏召回率必须同时满足的门禁。选模与阈值选择均最大化两者的较小值，不允许用牺牲其中一项换取另一项的高分，也不使用 18 条 App 固定音频选模。

## 数据协议修正

清单升级为版本 2，共 667 个十秒窗口、336 个来源组。按录音地点、原始录音或 Freesound 上传者严格隔离后，训练/校准/盲测分别为 457/111/99 条，来源组分别为 208/63/65 个。

误差审计发现 TUT Acoustic Scenes 的官方 `train` 标签表示普通列车场景，不能作为“高铁 / 城际列车”真值。协议已修正为：普通列车归入“其他”；只有元数据明确包含 high-speed、TGV、ICE 等证据且许可证可追溯的 FSD50K 音频才标为高铁。修正后高铁样本仅有训练 16、校准 3、盲测 3 条，这个规模不足以证明 95% 泛化能力。

## 模型与校准结果

最终候选使用 AudioSet 预训练的 `dymn10_as`，9,881,078 个参数。先冻结骨干训练分类头，再用 MPS 全量微调；checkpoint 按 `min(accuracy, macro_recall)` 选择。导出的 FP32 ONNX 为 40,041,944 字节，PyTorch/ONNX 最大绝对差为 `7.15e-7`，Mac CPU RTF 为 `0.00587`。

校准集结果：

| 类别 | 召回率 | 正确/总数 |
|---|---:|---:|
| 地铁 | 88.89% | 8/9 |
| 高铁 / 城际列车 | 33.33% | 1/3 |
| 商场 | 83.33% | 10/12 |
| 咖啡厅 / 餐厅 | 58.33% | 7/12 |
| 音乐现场 | 86.36% | 19/22 |
| 其他 | 69.81% | 37/53 |

全局未知拒识阈值扫描的最佳双指标阈值为 0.34，阈值前后都是准确率 73.87%、宏召回率 70.01%。准确率 Wilson 95% 区间为 65.00%–81.15%；按类别分层 bootstrap 的宏召回率 95% 区间为 58.90%–81.90%。这不仅没有达到 95%，现有样本量也无法给 95% 提供窄置信区间。

## 失败原因与下一步条件

主要误差不是 ONNX 导出或端侧速度，而是数据覆盖与纯音频可分性：明确高铁真值太少；咖啡厅经常被拒绝为“其他”；公交与地铁、普通列车与轨道交通、普通人群与音乐现场存在真实声学重叠。DCASE 2025 低复杂度十场景官方榜单的最佳系统准确率也只有 61.47%，说明开放环境纯音频场景识别本身远未接近通用 95%。

要继续保留 95% 门禁，下一批数据至少需要每类 100 条来源隔离的校准和盲测音频，并重点补充真实手机录制的中国高铁车内/站内、地铁、公交、咖啡厅和困难“其他”场景。若产品必须在数据不足时达到 95%，需要把任务收窄为封闭场景，或引入用户授权的定位、速度、蓝牙/网络等上下文；不能通过删除难样本、把普通列车改名为高铁或反复查看盲测来达成。
